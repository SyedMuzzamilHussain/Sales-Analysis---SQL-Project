SQL Sales Analysis Project

Project Overview
This project analyzes retail sales data using MySQL to understand revenue performance, product sales, customer spending, payment methods, and monthly sales trends.

The project demonstrates practical SQL skills used in data analysis and business reporting.

Objectives
- Calculate total sales revenue.
- Analyze revenue by product, category, city, and month.
- Identify top-performing orders and products.
- Analyze customer spending and repeat customers.
- Compare payment methods.
- Use advanced SQL queries to rank products and calculate revenue percentages.

Tools Used
- Database: MySQL
- SQL Editor: MySQL Workbench
- Version Control: GitHub

SQL Concepts Covered
- SELECT and WHERE
- Aggregate functions: SUM, AVG, COUNT
- GROUP BY and ORDER BY
- HAVING
- Subqueries
- Common Table Expressions (CTEs)
- Window functions
- RANK() and ROW_NUMBER()
- CASE statements
- Date-based analysis

Key Findings

1. Total Revenue
The dataset generated total sales revenue of **₹86,450**.

2. Revenue by Category
- Electronics: ₹48,600
- Furniture: ₹33,500
- Stationery: ₹4,350

Electronics contributed the highest revenue among the three categories.

3. Monthly Revenue
- January 2026: ₹39,250
- February 2026: ₹47,200

Revenue increased by approximately **20.25%** from January to February.

4. Revenue by City
- Jaipur: ₹38,400
- Delhi: ₹25,900
- Ajmer: ₹16,200
- Mumbai: ₹5,950

Jaipur generated the highest revenue in the dataset.

5. Average Order Value
The average order value was approximately **₹5,763.33**, based on 15 sales records.
